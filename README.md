# COACERO · Ventas y Facturación (Demo Interactiva)

Paquete estático 100% autónomo con datos ficticios para demostración en **GitHub Pages** (sin conexión a Microsoft Entra ID ni SharePoint).

## Cómo publicarlo en GitHub Pages
1. Crea un repositorio en GitHub (público o privado según tu plan) y sube todo el contenido de esta carpeta a la rama `main`.
2. Ve a **Settings → Pages** → **Deploy from a branch** → selecciona `main` y carpeta `/ (root)` → **Save**.
3. Abre la URL de GitHub Pages que te entrega GitHub y cambia entre las vistas **Gerencia**, **Vendedor** y **Facturación** desde el selector superior.
